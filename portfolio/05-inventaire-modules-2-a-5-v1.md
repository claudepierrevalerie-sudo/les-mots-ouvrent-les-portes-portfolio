# Inventaire des Modules 2 à 5

**Projet :** Les mots ouvrent les portes  
**Candidate :** Valérie  
**Statut :** inventaire de travail, à relire et à valider humainement

## Principe de présentation

Les modules rédigés seront présentés comme des productions co-construites et contrôlées par Yasmina et Valérie. Aucune distinction de propriété ou de niveau de contribution ne sera introduite dans le portfolio entre leurs deux contributions aux contenus.

Le Module 5 est définitivement annulé. La numérotation sera réexaminée à la fin du parcours. Le Module 6 pourra alors être rétrogradé en Module 5 afin de préserver la continuité du programme, sous réserve de la décision finale de Valérie et Yasmina.

Les modules seront présentés comme des productions secondaires qui prolongent le Module 1. Ils ne seront pas comptés artificiellement comme autant de preuves indépendantes lorsque plusieurs fichiers correspondent à une même production.

Le portfolio indiquera clairement la différence entre :

- une source de travail ;
- une version Markdown destinée à la relecture ;
- une version HTML imprimable ;
- un support de présentation ;
- une preuve de progression ;
- une validation humaine.

## Module 2 — Devenir inoubliable

**État observé :** contenu pédagogique substantiel, version HTML imprimable et supports de présentation disponibles ; statut général à relire.

**Angle :** laisser une trace utile dans une conversation grâce à une idée, une histoire, un mot juste ou une question qui élève l'échange.

**Productions repérées :**

- contenu Markdown du Module 2 ;
- version HTML imprimable ;
- source HTML imprimable et variante de relecture ;
- notebook de présentation ;
- présentation simple ;
- script de présentation de 5 à 7 minutes ;
- PDF source.

**Ce que le module montre :**

- capacité à construire un angle distinct du Module 1 ;
- organisation d'un contenu autour d'une compétence observable ;
- production d'exemples, d'exercices et d'une mise en pratique orale ;
- passage d'un contenu long à un support de présentation plus court.

**Preuve recommandée dans le portfolio :** une fiche synthétique du module accompagnée d'un lien vers la version HTML et d'un extrait du support de présentation. Les différentes versions ne doivent pas être comptées comme plusieurs productions.

**Vigilance :** plusieurs formulations ou faits présentés dans le module devront être relus avant diffusion, notamment lorsqu'ils sont formulés comme des résultats de recherche ou des chiffres. Une formulation pédagogique intéressante n'est pas automatiquement une donnée vérifiée.

## Module 3 — Converser avec des inconnus avec naturel

**État observé :** contenu Markdown et HTML complets, ainsi qu'un plan détaillé de travail. Le contenu est présenté comme co-rédigé et contrôlé par Yasmina et Valérie.

**Angle :** entrer dans une conversation, ajuster la distance relationnelle, faire circuler la parole et terminer l'échange avec élégance.

**Productions repérées :**

- contenu Markdown du Module 3 ;
- version HTML imprimable ;
- plan détaillé de travail ;
- exercices, scénarios et challenge de sept jours intégrés au contenu.

**Ce que le module montre :**

- traitement d'une situation relationnelle concrète ;
- structuration de règles, d'exemples avant/après et de scénarios ;
- souci d'adapter le niveau de langage au contexte et à la distance relationnelle ;
- capacité à transformer une difficulté sociale en compétence entraînable.

**Preuve recommandée dans le portfolio :** une fiche « situation → méthode → exemples → mise en pratique », avec la version HTML comme support consultable.

**Décision de contribution :** le contenu est présenté comme co-rédigé et contrôlé par Yasmina et Valérie. Cette décision remplace l'ancienne formulation qui laissait sa contribution à confirmer.

## Module 4 — Les erreurs de langage qui diminuent l'impact

**État observé :** contenu Markdown et HTML substantiels, avec versions de production et une version de suivi des étapes.

**Angle :** repérer les formulations qui affaiblissent un message et les transformer en phrases plus claires, précises, naturelles et crédibles.

**Productions repérées :**

- contenu Markdown du Module 4 ;
- version HTML imprimable ;
- version de production `module-4-final.md` ;
- document de suivi des étapes des Modules 3 à 5 ;
- exemples par profils professionnels et scripts de critique utile.

**Ce que le module montre :**

- méthode de transformation en trois niveaux : faible, corrigée, meilleure option ;
- capacité à travailler sur des situations professionnelles variées ;
- distinction entre critique d'un fait et attaque de la personne ;
- production d'une méthode réutilisable et non d'une simple liste de mots à éviter.

**Preuve recommandée dans le portfolio :** une courte étude avant/après montrant la méthode sur deux ou trois formulations, accompagnée du lien vers le module complet.

**Vigilance :** éviter de présenter les nombreux exemples comme autant de réalisations distinctes. Il s'agit d'une seule production pédagogique riche.

## Module 5 — Annulé

**Décision :** le Module 5 est définitivement annulé. Il ne sera pas présenté comme une production, ni fusionné artificiellement avec le Module 4.

La numérotation globale sera revue lorsque l'ensemble des modules sera stabilisé. Le Module 6 pourra devenir le nouveau Module 5 pour conserver une progression continue.

## Sélection recommandée pour le portfolio

Le portfolio final pourrait présenter :

1. le Module 1 comme production principale et preuve de progression numérique ;
2. le Module 2 comme production consacrée à la mémorabilité et à la présentation orale ;
3. le Module 3 comme production consacrée à la relation et à la conversation ;
4. le Module 4 comme production consacrée à la précision du langage ;
5. le futur Module 5, issu du Module 6 après décision de renumérotation ;
6. les séances 18 à 20 comme évolution web transversale du projet ;
7. les séances 21 à 24 comme progression dans l'organisation, le contrôle et la documentation.

Cette sélection est plus honnête et plus lisible que la présentation de cinq modules prétendument équivalents et tous définitivement achevés.
