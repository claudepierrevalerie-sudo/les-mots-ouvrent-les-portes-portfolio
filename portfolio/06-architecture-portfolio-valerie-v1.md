# Architecture du portfolio de Valérie

**Projet :** Les mots ouvrent les portes  
**Candidate :** Valérie  
**Co-rédaction et co-contrôle des contenus :** Yasmina et Valérie  
**Destinataires :** Professeur Abderrahman et participantes et participants au Challenge 100 Jours  
**Version :** architecture éditoriale V1  
**Périmètre retenu :** contenus disponibles jusqu'au Module 4  
**Statut :** structure de travail, à valider humainement

## 1. Positionnement du portfolio

Ce portfolio ne constitue pas une candidature à la finale. Il présente l'aboutissement fidèle d'un parcours commencé sans expérience préalable de la programmation, puis développé progressivement avec l'aide de l'IA, la co-rédaction avec Yasmina et un contrôle humain continu.

Il doit permettre au lecteur de comprendre :

- le projet personnel et pédagogique poursuivi ;
- les contenus réellement produits ;
- la transformation progressive des contenus en supports et en pages web ;
- les méthodes apprises pour organiser, corriger, documenter et contrôler ;
- les limites encore présentes ;
- ce qui pourra être poursuivi après la clôture du challenge.

## 2. Structure proposée

### Ouverture — Un parcours qui a pris forme

- titre : **Les mots ouvrent les portes** ;
- nom affiché : Valérie ;
- mention de la co-rédaction et du co-contrôle avec Yasmina ;
- phrase de positionnement : une formation sur la qualité des mots, de la parole et des échanges ;
- statut : portfolio de participante, non candidature à la finale.

### Partie 1 — Le projet

- origine et intention ;
- besoin traité ;
- publics envisagés ;
- promesse pédagogique ;
- place de la précision, de la présence et de la relation dans le parcours.

### Partie 2 — La production principale

**Module 1 — Les 7 premières secondes**

- objectif et résultat observable ;
- contenu Markdown et version HTML ;
- cinq exercices, quiz et engagement terrain ;
- mini-site comme déclinaison numérique ;
- progression du contenu vers la page web, les données et la PWA ;
- limites et validations encore requises.

### Partie 3 — Les productions pédagogiques

Présenter les modules comme des productions co-rédigées et co-contrôlées par Yasmina et Valérie.

- Module 2 : devenir inoubliable ;
- Module 3 : converser avec des inconnus avec naturel ;
- Module 4 : les erreurs de langage qui diminuent l'impact ;
- Module 5 initialement prévu : annulé, mentionné uniquement dans la chronologie des décisions.

Pour chaque production retenue :

- besoin ou situation traitée ;
- résultat pédagogique ;
- formats disponibles ;
- exemple représentatif ;
- preuve consultable ;
- statut exact ;
- limite ou amélioration à poursuivre.

### Partie 4 — La progression numérique

Présenter une seule histoire de progression, sans compter chaque copie comme une nouvelle production :

1. contenu pédagogique initial ;
2. support imprimable ;
3. mini-site V1 ;
4. version dynamique avec données et interactions ;
5. éléments PWA et contrôle local ;
6. documentation du projet et distinction entre accessibilité, contrôle et validation.

### Partie 5 — La méthode de travail

- cadrer une intention ;
- structurer un contenu ;
- travailler avec l'IA ;
- relire et corriger ;
- organiser les fichiers ;
- contrôler un résultat ;
- documenter une décision ;
- reconnaître ce qui n'est pas encore validé.

La formule directrice pourra être conservée :

> L'IA assiste. Les humaines cadrent, relisent, contrôlent et décident.

### Partie 6 — Une progression de débutante en programmation

Cette partie expliquera avec simplicité ce qui a été appris :

- comprendre la différence entre fichier source et version affichée ;
- lire une structure HTML ;
- repérer le rôle du CSS et du JavaScript ;
- suivre des données JSON ;
- utiliser un serveur local ;
- comprendre les notions de dépôt, README, publication et contrôle ;
- demander de l'aide sans abandonner la responsabilité des choix.

Il ne s'agit pas de présenter une expertise de développeuse, mais une autonomie progressive suffisante pour comprendre, expliquer et contrôler les productions réalisées.

### Partie 7 — Les limites et les décisions

- Module 5 annulé ;
- numérotation définitive différée ;
- le Module 6 n'est pas intégré à cette version du portfolio ;
- la suite du programme pourra être étudiée ultérieurement, avec une nouvelle décision de numérotation ;
- validations humaines finales encore à obtenir ;
- tests préparés à distinguer des tests effectivement exécutés ;
- droits des images, citations et ressources à contrôler ;
- présentation globale à harmoniser lorsque le contenu disponible sera stabilisé.

### Conclusion — Finir avec élégance

- ce qui a été accompli ;
- ce qui a été appris ;
- ce qui peut être partagé localement ;
- ce qui reste à poursuivre ;
- remerciement à Yasmina, au professeur et au groupe ;
- prochaine étape concrète après le challenge.

## 3. Statut provisoire de la numérotation

La numérotation actuelle des fichiers sources est conservée pour ne pas altérer les traces historiques.

Décision éditoriale différée :

- le Module 5 est annulé ;
- le Module 6 reste hors du périmètre de cette version ;
- une éventuelle nouvelle numérotation sera étudiée séparément, avec les titres, prérequis et renvois internes correspondants ;
- aucune production originale ne sera renommée avant cette décision finale.

## 4. Sélection initiale des preuves

Le portfolio ne cherchera pas à exposer tous les fichiers. Pour cette première version, il retiendra :

- une preuve de cadrage du projet ;
- le Module 1 comme production principale ;
- une fiche synthétique pour les Modules 2, 3 et 4 ;
- la progression web des séances 18 à 20 ;
- la progression d'organisation et de contrôle des séances 21 à 24 ;
- une copie locale contrôlée destinée au partage.

## 5. Décision de périmètre

Le portfolio peut être considéré comme une production de qualité en s'arrêtant au Module 4. Ce périmètre est cohérent : il comprend une production principale, trois productions pédagogiques complémentaires, une progression numérique et une méthode de contrôle documentée.

Le Module 6 sera conservé dans les sources du projet et pourra faire l'objet d'une suite ultérieure. Il ne sera pas présenté comme une lacune à masquer, mais comme une étape volontairement laissée hors du périmètre de cette version afin de préserver sa qualité et son homogénéité.

## 6. Prochaine étape

Rédiger les fiches synthétiques des Modules 2, 3 et 4, puis assembler une première version locale contrôlée du portfolio jusqu'au Module 4.
