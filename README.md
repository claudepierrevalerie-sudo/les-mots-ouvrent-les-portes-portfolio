# Copie préparée pour GitHub Pages

Cette copie est préparée pour GitHub Pages afin de faciliter la publication du site Web.
La publication n'est pas exécutée automatiquement dans ce dossier.
Une autorisation explicite est requise avant toute mise en ligne ou publication publique.

## Contenu

- `index.html` : page d'entrée du portfolio ;
- `portfolio.html` : copie de la page d'entrée historique ;
- `modules/` : versions Markdown et HTML des Modules 1 à 4 ;
- `preuves/` : preuves lisibles et sources documentaires ;
- `mini-site/` : mini-site complet du projet ;
- `portfolio/pitch-3-minutes-valerie-v2.html` : pitch imprimable ;
- `portfolio/pitch-3-minutes-valerie-v2.md` : script du pitch ;
- `index.html` : accès au pitch vidéo BigVu depuis la section « Présentation orale ».

## Vidéo du pitch

La vidéo « Pitch séance 28 » est hébergée sur BigVu. Le portfolio contient un lien externe vers l'enregistrement de Valérie, d'une durée observée d'environ 4 min 03 s. La vidéo n'est pas copiée dans ce dépôt.
