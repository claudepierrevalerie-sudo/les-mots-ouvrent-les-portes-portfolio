Séance 24 · Preuve de contrôle

README, contrôle et preuve globale

La séance 24 applique un workflow à une modification réelle, utile et limitée du README du mini-site.

Résultat observable : le README local décrit désormais le statut de publication observé et l'URL GitHub Pages contrôlée.

Contrôles effectués

  • lecture du README ;
  • contrôle du dépôt local, de la branche et de l'historique ;
  • vérification de l'URL publique ;
  • modification limitée au README ;
  • relecture du diff et `git diff --check` réussi ;
  • aucun commit, push ou nouvelle publication exécuté.

Limite

La correction locale et l'accessibilité de l'URL ne constituent pas à elles seules une validation pédagogique finale.
