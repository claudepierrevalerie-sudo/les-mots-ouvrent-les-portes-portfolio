Une correction réelle et limitée

Ce workflow décrit une méthode réutilisable pour corriger un document sans élargir inutilement le périmètre.

Étapes

1. Lire le README avant toute modification.
2. Contrôler le dépôt local, sa branche, son remote et son historique.
3. Vérifier l'accessibilité de l'URL documentée.
4. Modifier uniquement le fichier autorisé.
5. Relire le diff et exécuter `git diff --check`.
6. Vérifier que seul le fichier prévu est modifié.
7. Conserver les actions distantes non exécutées sans autorisation.

Statut

Workflow exécuté localement, contrôlé et soumis à validation humaine.
