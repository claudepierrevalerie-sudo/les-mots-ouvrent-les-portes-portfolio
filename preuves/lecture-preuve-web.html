Séance 18 · Preuve web

Première production du mini-site

Cette preuve relie le projet pédagogique « Les mots ouvrent les portes » à une première réalisation web locale.

Éléments produits : une page structurée, une navigation, une présentation du problème, les bénéfices, les modules, des exemples avant/après et une entrée vers le Module 1.

Ce que la preuve montre

  • transformation de contenus sources en page web ;
  • organisation mobile-first ;
  • navigation clavier et menu mobile préparés ;
  • distinction entre informations disponibles et éléments encore absents.

Limite

Cette preuve atteste la production du mini-site. Elle ne vaut pas validation pédagogique définitive ni autorisation générale de publication.
